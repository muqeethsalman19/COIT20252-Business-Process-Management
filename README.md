# COIT20252-Business-Process-Management

## Introduction to Process Analysis

Process analysis is a key phase of the BPM Life Cycle that focuses on understanding how a process currently operates and how effectively it supports organisational goals. It involves examining activities, handoffs, business rules, and performance measures to identify inefficiencies, risks, and improvement opportunities (ABPMP, 2019, p.130). Through this portfolio, I explore how process analysis is applied using structured methods, analytical tools, and real examples, supported by genuine artefacts and reflective insights that demonstrate my learning.

## Core BPM Concepts Related to Process Analysis

Process analysis is grounded in core BPM principles such as end‑to‑end process thinking, performance‑driven management, and continuous improvement. BPM treats processes as organisational assets that must be measured, monitored, and optimised over time (ABPMP, 2019, p.40). Before any redesign, organisations must understand the AS‑IS process, including inputs, outputs, constraints, and cross‑functional interactions. Analysis also supports strategic alignment by ensuring processes contribute to organisational goals. By examining variation, capacity, and handoffs, organisations gain visibility into inefficiencies and value‑adding activities. These concepts form the foundation for structured and evidence‑based process analysis.
