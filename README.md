# COIT20252-Business-Process-Management

##Introduction to Process Analysis
Process analysis is a key phase of the BPM Life Cycle that focuses on understanding how a process currently operates and how effectively it supports organisational goals. It involves examining activities, handoffs, business rules, and performance measures to identify inefficiencies, risks, and improvement opportunities (ABPMP, 2019, p.130). Through this portfolio, I explore how process analysis is applied using structured methods, analytical tools, and real examples, supported by genuine artefacts and reflective insights that demonstrate my learning.
